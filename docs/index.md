# Jupyter Foundation Community Funding Reports

Progress reports for funded community proposals approved by the Jupyter Foundation Governing Board.
Each page collects one project's bi-monthly reports in chronological order.
See [the repository README](https://github.com/jupyter-governance/funding-proposals#readme) for how proposals are submitted and how reporting works.

:path: projects/*/*.md
:columns: title,status,latest report
:sort: sortdate-desc
:limit: 1000
:::
