## Summary of Work Completed

- The first stable version, v1.0 was published, along with two patch releases (https://github.com/jupyterlab/jupyter-builder/blob/main/CHANGELOG.md#102)
- Rspack version was updated to 2.0 (https://github.com/jupyterlab/jupyter-builder/pull/93)
- Downstream tests were added (https://github.com/jupyterlab/jupyter-builder/pull/91)
- Linters were set up for code quality enforcement (https://github.com/jupyterlab/jupyter-builder/pull/96)
- Core-metadata automatic updates were set up (https://github.com/jupyterlab/jupyter-builder/pull/119)
- The set of dependencies was further reduced and set of network calls restricted (https://github.com/jupyterlab/jupyter-builder/pull/102, https://github.com/jupyterlab/jupyter-builder/pull/108, https://github.com/jupyterlab/jupyter-builder/pull/118)
- Compatibility with old `@jupyterlab/builder` was improved for smoother transition (https://github.com/jupyterlab/jupyter-builder/pull/98)
- We investigated and patched the breakage to builder packages due to a new webpack release which affected both `@jupyterlab/builder` and the new `jupyter-builder` before rspack transition (https://github.com/webpack/webpack/pull/20860, https://github.com/krassowski/webpack-licence-repro, https://github.com/jupyterlab/jupyterlab/pull/18929, https://github.com/jupyterlab/jupyterlab/pull/19021)

---

We track most of the issues and pull requests associated with this proposal in [this public GitHub project](https://github.com/orgs/jupyterlab/projects/12/views/4?sliceBy%5Bvalue%5D=jupyter-builder).
